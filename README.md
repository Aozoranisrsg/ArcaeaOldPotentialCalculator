# Arcaea旧版潜力值计算器

上传Arcaea成绩文件（CSV），计算旧版潜力值（b30）。
[在线使用](https://aozoranisrsg.github.io/ArcaeaOldPotentialCalculator/)

## 获取成绩文件
有两种方法获取成绩文件。
本质上都是用Yurisaki机器人的功能，所以在此之前你需要完成如下操作：
1. 绑定Yurisaki机器人：在群聊里@机器人发送/a bind xxxxxxxxx，将其中的x替换为你的Arcaea好友码。或者私聊发送指令也可以。
2. 声明账号所有权：私聊机器人发送/a account claim，随后机器人会引导你完成如下操作：
  1. 切换搭档：打开游戏，把你的搭档和头像都切换为初始对立（切换头像：先选择一个搭档，再点搭档页右边快速设置，点击四个格子里面顶上那个）（技能锁不锁没关系）
  2. 验证：对机器人发送/a account check，等待验证。
然后可以通过以下两种方式获得成绩文件。

### Yurisaki网站导出
打开Yurisaki网站：https://arcaea.yurisaki.top
初次打开需要登录，用户名就是你的Arcaea用户名或者你的好友码，密码对机器人发送/a account otp获得（需要先声明账号所有权）
登录后网页左侧找到玩家数据，进入后等待加载完成，点击导出按钮即可。
